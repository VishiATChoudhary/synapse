  • Trigger in the composer: the provider's logo, the model and its effort, plus a chevron. ⇧⌘M opens it.
  • Rail on the left: Favorites, then one square per agent (Claude, Codex, Gemini, Antigravity, OpenCode). A bar marks the current one; ⇧⌘↑↓ switches.
  • List with search: the agent's models from its own CLI (what Synapse already reads), current ones first, older ones under "Older". A star pins favorites, NEW marks new ones.
  • Effort column for models that have it (Claude, Codex), with bars like T3 and the default tagged.
  • Footer: Standard or Fast as a segmented pill, and the permission mode.
  • Keyboard like T3: ← → between columns, ↑ ↓ in a list, Enter picks, Esc closes.
  • Starting a new session uses the same picker, so the model is chosen the same way everywhere.
